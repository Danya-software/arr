# Лабораторна робота: Масиви

Предмет: «Моделювання та аналіз програмного забезпечення»

У програмі реалізовано 10 функцій для роботи з масивами:

1. Максимальна кількість одиниць підряд.
2. Кількість чисел із парною кількістю цифр.
3. Квадрати відсортованого масиву у відсортованому порядку.
4. Подвоєння нулів у масиві фіксованої довжини.
5. Об'єднання двох відсортованих масивів.
6. Видалення дублікатів із відсортованого масиву.
7. Перевірка існування числа та його подвійника.
8. Перевірка, чи є масив дійсним гірським масивом.
9. Заміна елементів найбільшим елементом праворуч.
10. Переміщення парних чисел на початок масиву.

## Як запустити у VS Code

1. Відкрий папку з файлом `main.cpp` у Visual Studio Code.
2. Відкрий Terminal → New Terminal.
3. Скомпілюй програму командою:

   ```powershell
   g++ -std=c++17 main.cpp -o main.exe
   ```

4. Запусти:

   ```powershell
   .\main.exe
   ```

5. Введи номер завдання від 1 до 10 та дані, які попросить програма.

## Приклад перевірки

Для завдання 1 можна ввести:

```text
1
6
1 1 0 1 1 1
```

Очікуваний результат: `3`.

Для завдання 3 можна ввести:

```text
3
5
-4 -1 0 3 10
```

Очікуваний результат: `[0, 1, 9, 16, 100]`.
